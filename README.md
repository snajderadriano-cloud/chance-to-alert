# Chance to Alert.App 🛡️

**Chance to Alert** — это интеллектуальный предиктивный бэкенд раннего оповещения о воздушных угрозах (БПЛА Shahed, баллистика, крылатые ракеты, тактическая авиация) на основе мониторинга Telegram-каналов и открытых источников данных.

Сервис рассчитывает вероятность тревоги (**0–100%**) и ориентировочное время подлёта (ETA) для заданного района (**по умолчанию: Одесский район и Одесская область**), предоставляя пользователю фору в **20–40 минут** до включения официальных сирен.

---

## 🎯 Основные возможности

1. **Telegram Ingestion & NLP Parsing**:
   - Автоматический парсинг постов мониторинговых каналов на украинском языке (типы целей, количество, направления движения, высоты, векторы, отбои).
   - Защита от отравления данных (`TextSanitizer`): вырезание невидимых unicode-символов (zero-width characters), нормализация латинских/кириллических гомоглифов, нейтрализация инъекций.

2. **Гео-справочник (Regional Gazetteer)**:
   - Встроенный каталог координат населенных пунктов Одесского района (Одесса, Черноморск, Южное, Фонтанка, Таирово, Овидиополь, Затока, Беляевка и др.).
   - Порты Дуная (Измаил, Рени, Килия, Вилково) и морские транзитные коридоры Черного моря и Крыма.
   - Пространственная дискриминация: атака на порты Дуная (~190 км от Одессы) не приводит к ложной тревоге в Одесском районе.

3. **Математический движок вероятности (Tactical Scoring Engine)**:
   - Экспоненциальное затухание актуальности информации (half-life decay: $T_{1/2}$ для каждого типа угрозы).
   - Пространственное затухание по геодезической формуле Haversine и согласование вектора направления (азимут / пеленг).
   - Логарифмический мультипликатор роя/количества целей ($M(n) = 1 + 0.3 \cdot \log_2(n)$).
   - Вероятностное объединение независимых угроз: $P_{\text{total}} = 1 - \prod_{i=1}^k (1 - P_i)$.
   - 4 уровня опасности: **GREEN (0-24%)**, **YELLOW (25-49%)**, **ORANGE (50-74%)**, **RED (75-100%)**.

4. **Хранилище с криптографическим аудитом**:
   - Дедупликация по SHA-256 хешу содержимого постов.
   - Отслеживание редакций сообщений (edit revisions).
   - Неизменяемый хеш-чейн аудит-лог (SHA-256 blockchain-style audit log).

5. **REST API & Real-time WebSocket**:
   - Высокопроизводительный асинхронный сервер на FastAPI.
   - Эндпоинты для мобильных шорткатов (iOS Shortcuts / Android widgets), веб-интерфейсов и Home Assistant.
   - WebSocket стрим мгновенных уведомлений (`/api/v1/ws`).

## 📂 Структура проекта

```
Chance to Alert.App/
├── app/
│   ├── api/                 # REST & WebSocket API, схемы Pydantic
│   │   ├── v1/router.py     # Эндпоинты /probability, /threats, /simulate, /ws
│   │   ├── deps.py          # Внедрение зависимостей (AppState)
│   │   └── schemas.py       # Pydantic модели запросов/ответов
│   ├── config.py            # Загрузчик YAML и переменных окружения
│   ├── domain/              # Чистое доменное ядро (ноль внешних зависимостей)
│   │   ├── entities.py      # Сущности (GeoCoordinate, ThreatSignal, TargetPreset)
│   │   ├── enums.py         # Перечисления (ThreatType, AlertLevel, MovementSpeedClass)
│   │   ├── geo.py           # Геодезия Haversine, азимуты, пеленг, ETA
│   │   └── scoring.py       # Движок скоринга, затухание, объединение вероятностей
│   ├── ingestion/           # Адаптеры источников (Telegram, Mock, Alerts API)
│   ├── processing/          # NLP парсер, украинский лексикон, газетир, санитизация
│   ├── services/            # Сервисы жизненного цикла треков, скоринга и бродкаста
│   ├── storage/             # SQLite с дедупликацией и хеш-чейном
│   └── main.py              # Точка входа FastAPI
├── config/
│   ├── presets_odesa.yaml   # Географические пресеты (Одесский район, Область)
│   └── channels.yaml        # Список Telegram-каналов источников
├── docs/                    # Документация архитектуры, API и моделей
├── tests/                   # 101 тест (юнит, интеграционные, 7 E2E сценариев)
└── pytest.ini               # Конфигурация pytest
```

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install fastapi uvicorn pydantic pyyaml starlette httpx pytest pytest-asyncio
```

### 2. Запуск сервера
```bash
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
Интерактивная документация Swagger UI будет доступна по адресу:
👉 `http://localhost:8000/docs`

### 3. Запуск тестов
```bash
python -m pytest tests/ -v
```
Все 101 тест выполняются за ~0.5 секунды.

## 📡 Основные API Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/health` | Проверка здоровья сервиса |
| `GET` | `/api/v1/probability?preset=odesa_district` | Текущий шанс тревоги, уровень угрозы, ETA и саммари |
| `GET` | `/api/v1/threats/current` | Список активных воздушных целей и векторов |
| `GET` | `/api/v1/threats/history` | История зафиксированных событий с пагинацией |
| `GET` | `/api/v1/config/presets` | Доступные районы и пресеты |
| `POST` | `/api/v1/simulate` | Симуляция/инжест сообщения из Telegram |
| `WS` | `/api/v1/ws` | WebSocket поток обновлений в реальном времени |

## 📱 Интеграция с iOS Shortcuts / Виджетами

Для получения шанса тревоги на iPhone в виде виджета или шортката достаточно отправить `GET` запрос:
```
GET http://<YOUR_IP>:8000/api/v1/probability?preset=odesa_district
```
Ответ:
```json
{
  "target_district": "odesa_district",
  "probability_percent": 78,
  "alert_level": "RED",
  "active_threat_count": 2,
  "primary_threat_type": "SHAHED",
  "estimated_time_to_impact_minutes": 22,
  "summary": "RED Alert (78%): 2 active threat track(s) for odesa_district. Primary: SHAHED at 38.4 km ETA ~22m.",
  "calculated_at": "2026-11-23T13:10:00Z"
}
```
Подробное руководство по настройке шорткатов и Scriptable-виджетов смотрите в [`docs/INTEGRATION_GUIDE.md`](docs/INTEGRATION_GUIDE.md).
