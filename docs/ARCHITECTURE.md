# Архитектура системы (System Architecture) 🏛️

## 1. Концепция Clean Hexagonal Architecture

Архитектура бэкенда спроектирована по принципам чистой архитектуры:
```
┌────────────────────────────────────────────────────────┐
│                   API / Presentation                   │
│         FastAPI, REST Router, WebSocket Stream         │
├────────────────────────────────────────────────────────┤
│                  Application Services                  │
│   TrackingService, ProbabilityService, Broadcaster     │
├──────────────────────────┬─────────────────────────────┤
│   Ingestion & Storage    │       Processing Layer      │
│  TelegramFeed, SQLite DB │ Sanitizer, Gazetteer, NLP   │
├──────────────────────────┴─────────────────────────────┤
│                      Domain Core                       │
│     Entities, Enums, Haversine Geo, Scoring Math       │
│             (Zero external dependencies)               │
└────────────────────────────────────────────────────────┘
```

### Доменный уровень (`app/domain/`)
- Полная изоляция от внешних фреймворков и библиотек.
- Математика геодезических вычислений на сфере WGS84:
  - Расстояние по дуге большого круга (Haversine);
  - Начальный путевой угол (настоящий азимут / forward azimuth);
  - Угловая разница пеленгов с нормализацией через modulo 360°;
  - Фактор сонаправленности вектора движения $\cos(\Delta\theta)$;
  - Кинематический расчет времени подлета $t = d / v$.
- Алгоритм скоринга вероятностей с полупериодом затухания и объединением независимых вероятностей.

### Уровень обработки (`app/processing/`)
- `SignalPoisoningGuard` / `TextSanitizer`: удаление невидимых unicode-символов, нормализация гомоглифов, чистка управляющих символов.
- `RegionalGazetteer`: гео-справочник населенных пунктов Одесчины и юга Украины с поддержкой падежей и склонений украинского языка.
- `ThreatParser`: выделение типов угроз, количества, направлений и векторов движения.

### Уровень сервисов и хранения (`app/services/`, `app/storage/`)
- `ThreatTrackingService`: хранение активных треков угроз, сопоставление (corroboration) сообщений из разных каналов с повышением уверенности (confidence score), очистка устаревших треков.
- `SQLiteStorage`: хранение с дедупликацией по SHA-256 хешу контента и криптографическим хеш-чейном для аудита.
- `BroadcasterService`: неблокирующая рассылка push-сообщений подписчикам WebSocket.

### Уровень API (`app/api/`)
- Валидация входных и выходных данных через Pydantic v2.
- CORS-мидлвар для свободного подключения клиентских веб-интерфейсов, браузерных расширений и локальных шорткатов.
- OpenAPI / Swagger автогенерация документации.
